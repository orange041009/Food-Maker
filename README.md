# 食光味道 · 家常菜谱网站

一个纯前端（HTML + CSS + JS，无需构建、无需服务器端）的美食菜谱网站示例。

## 功能

- **精选食谱**：首页展示 6 道精选菜品卡片（图片占位、名称、简介）。
- **分类浏览**：按中国八大菜系分类——川菜、粤菜、鲁菜、闽菜、浙菜、湘菜、徽菜、苏菜。
- **今日主厨推荐**：根据当天日期确定性选取（非随机），当天固定不变，次日自动切换。
- **搜索**：支持按菜名、简介或食材关键词搜索。
- **食谱详情**：点击任意菜品卡片，弹层展示完整食材清单与烹饪步骤。
- **响应式设计**：适配手机与电脑屏幕。

内置 32 道示例菜谱（每个菜系 4 道），数据全部保存在 `data.js` 中，图片使用 emoji + 渐变色占位，无需联网即可完整浏览。

## 本地预览

无需安装任何依赖，两种方式均可：

1. **直接打开**：双击 `index.html`，用浏览器直接打开即可（部分浏览器对本地文件的 `file://` 协议限制较少，此项目未使用 fetch，可直接打开）。
2. **本地静态服务器**（推荐）：

   ```bash
   cd recipe-site
   python3 -m http.server 8080
   ```

   然后浏览器访问 `http://localhost:8080`。

