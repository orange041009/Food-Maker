# 🍚 食光味道 (Food-Maker)

> AI 驱动的智能菜谱规划网站 — 72 道菜 · 18 大菜系 · 多维筛选 · AI 推荐

## ✨ 功能

- 🎯 **多维智能筛选** — 用餐时间、口味、过敏原、菜系、人数等 8 维度精准匹配
- 🤖 **AI 烹饪助手** — DeepSeek 驱动的智能对话，推荐菜谱、解答疑问
- 📋 **可执行菜谱计划** — 按难度、耗时、匹配度排序，近似推荐补位
- 🛒 **一键购买食材** — 京东/美团/盒马联盟链接跳转
- 💰 **食材估价** — 211 种食材市场参考价，每道菜预估总成本
- 🎬 **教学视频搜索** — B站/YouTube/抖音/下厨房一键跳转
- 📸 **专属菜品图鉴** — 72 张 SVG 定制视觉卡片，菜名+emoji+菜系
- 📱 **移动端优化** — 惯性滚动、横向滑动、底部弹出筛选面板

## 🚀 快速启动

纯静态前端，零依赖：

```bash
# 启动静态服务
cd Food-Maker
python3 -m http.server 8080

# 可选：启动 AI 代理（需要 DeepSeek API Key）
export DEEPSEEK_API_KEY=sk-...
python3 ai-proxy.py
```

打开 `http://localhost:8080`

## 🛠 技术栈

- 纯 HTML/CSS/JS — 零框架，零构建
- SVG 矢量图 — 每道菜定制视觉卡片
- DeepSeek Chat API — AI 对话与智能搜索
- CSS Grid + Flexbox — 响应式布局
